# Flomo to Obsidian 插件

将 [flomo](https://flomoapp.com) 笔记自动同步到 Obsidian vault 的插件。

## ✨ 功能特性

### 🔄 API 自动同步
- **一键登录**：在插件设置中点击登录按钮，弹出 flomo 登录窗口，登录后自动获取认证凭证
- **手动输入 Token**：如自动登录不可用，可手动从浏览器开发者工具中获取 Token 粘贴
- **增量同步**：首次同步后，后续只拉取新增/更新的笔记
- **定时自动同步**：可设置自动同步间隔（默认 30 分钟）
- **同步起始日期**：可指定只同步某个日期之后的笔记
- **Token 自动验证**：插件启动时自动检查 Token 是否有效，过期则提示重新登录

### 📄 HTML 文件导入
- 支持导入 flomo 导出的 HTML 文件
- 解析 memo 内容、时间戳、标签、图片

### 📝 Markdown 转换
- 自动生成 YAML frontmatter（创建时间、更新时间、来源、ID）
- 标签转换为 Obsidian `#tag` 格式（支持 `#tag/subtag` 多级标签）
- 高亮文本转换为 `==高亮==` 格式
- 支持两种写入模式：
  - **按日期合并**：同一天的 memo 合并到一个文件（如 `flomo-2024-01-15.md`）
  - **独立文件**：每条 memo 生成一个文件

### 🔁 更新（Upsert）逻辑
- 新笔记 → 创建新文件
- 已存在的笔记 → 更新文件内容
- 不会创建重复文件

---

## 📦 安装

1. 将以下文件复制到 Obsidian vault 的 `.obsidian/plugins/flomo-to-obsidian/` 目录：
   - `main.js`
   - `manifest.json`
   - `styles.css`
2. 打开 Obsidian → **设置** → **第三方插件** → 关闭**安全模式**
3. 找到 **Flomo to Obsidian** → 点击**启用**

---

## 🚀 使用说明

### 首次设置

1. 打开 **设置** → **Flomo to Obsidian**
2. 设置 **导入目标文件夹**（默认：`flomo`）
3. 选择是否 **按日期合并** memo

### 登录 flomo

#### 方式一：自动登录（推荐）
1. 在插件设置中点击 **「🔑 登录 flomo」** 按钮
2. 在弹出的登录窗口中输入 flomo 账号密码
3. 登录成功后自动获取凭证，窗口自动关闭

#### 方式二：手动输入 Token
1. 在浏览器中打开 [v.flomoapp.com](https://v.flomoapp.com) 并登录
2. 按 **F12** 打开开发者工具 → 切换到 **Network（网络）** 面板
3. 点击 **Fetch/XHR** 过滤器，然后刷新页面
4. 点击任意一个 API 请求 → 在 Headers 中找到 **Authorization** 的值
5. 复制完整的值（以 `Bearer` 开头），粘贴到插件设置中的 Token 输入框

### 同步笔记

#### 手动同步
- 点击 Obsidian 左侧栏的 **🔄 同步图标**
- 或在设置中点击 **「📥 立即同步」** 按钮
- 或使用命令面板（`Ctrl+P`）→ 搜索 **「Flomo: 同步笔记」**

#### 自动同步
1. 在设置中开启 **「启用自动同步」**
2. 设置 **同步间隔**（默认 30 分钟）
3. 插件会在后台定时拉取新笔记

#### 指定同步时间范围
1. 在 **「同步起始日期」** 中填写日期（格式：`YYYY-MM-DD`，如 `2024-01-01`）
2. 只有该日期之后创建的笔记会被同步
3. 修改起始日期后会**自动重置同步状态**

#### 重新同步
如果需要重新拉取所有笔记：
1. 点击设置中的 **「🔄 重置同步状态」** 按钮
2. 再点击 **「📥 立即同步」**
3. 或使用命令面板 → **「Flomo: 完整重新同步」**

### 导入 HTML 文件
1. 从 flomo 导出 HTML 文件
2. 使用命令面板（`Ctrl+P`）→ 搜索 **「Flomo: 导入 HTML」**
3. 选择导出的 HTML 文件

## ⚙️ 设置项说明

| 设置 | 说明 | 默认值 |
|------|------|--------|
| 导入目标文件夹 | flomo 笔记保存的 vault 子文件夹 | `flomo` |
| 按日期合并 | 同一天的 memo 合并到一个文件 | ✅ 开启 |
| 下载图片 | 将 memo 中的图片下载到本地 | ❌ 关闭 |
| 图片文件夹 | 下载的图片保存位置 | `flomo/attachments` |
| 同步起始日期 | 只同步该日期之后的笔记 | 空（全部） |
| 启用自动同步 | 定期自动拉取新笔记 | ❌ 关闭 |
| 同步间隔 | 自动同步的间隔时间 | 30 分钟 |

---

## 🔧 命令面板

| 命令 | 说明 |
|------|------|
| Flomo: 导入 HTML | 从 flomo 导出的 HTML 文件导入笔记 |
| Flomo: 同步笔记 | 从 flomo API 拉取新笔记 |
| Flomo: 完整重新同步 | 重置同步状态并重新拉取所有笔记 |
| Flomo: 登录 flomo | 打开 flomo 登录窗口获取凭证 |

## 📁 生成的文件格式

### 按日期合并模式

文件名：`flomo-2024-01-15.md`

```markdown
---
date: 2024-01-15
source: flomo
---

## 09:30

这是一条 memo 的内容

#标签1 #标签2

---

## 14:20

这是另一条 memo

#工作/项目A
```

### 独立文件模式

文件名：`flomo-2024-01-15-0930-memo内容前30字.md`

```markdown
---
created: 2024-01-15T09:30:00
updated: 2024-01-15T09:30:00
source: flomo
flomo_id: flomo-api-xxxxx
---

这是一条 memo 的内容

#标签1 #标签2
```

---

## ⚠️ 注意事项

- 本插件使用 flomo 非公开 API，如 flomo 更新 API 接口可能导致功能异常
- Token 有效期有限，过期后需要重新登录
- 建议首次同步前先设置好同步起始日期，避免拉取过多历史数据
- 免费和付费账号均可使用 API 同步功能
